## 1. Core Objective

Implement Phase 1 of the CLI Tool Roadmap: four library-level features that make
SwiftZIP archives fully interoperable with Info-ZIP for standard use cases.

## 2. Design Decisions

- **Decision:** Use system zlib for compression levels, keep Compression framework as default
- **Rationale:** Apple's Compression framework is fixed at zlib level 5 with no parameter to change it. System zlib is available on all Swift platforms with zero vendored code.
- **Alternatives Considered:** Pure-Swift deflate encoder (too large a scope), always use zlib (would lose Compression framework's optimizations for default case)

- **Decision:** Extended timestamps (UT) preferred over DOS timestamps in reader
- **Rationale:** UT provides 1-second precision vs DOS 2-second; Info-ZIP always writes UT fields
- **Alternatives Considered:** Always use DOS (simpler but loses precision)

- **Decision:** Project moved from `Playgrounds/Math/` to `Tools/`
- **Rationale:** User decided this is a real tool, not a playground experiment

  `/usr/include/zlib.h` and links `-lz`. No vendored C source.
- `Deflate.compress(_:level:)` dispatches to Compression framework when level is nil,
  zlib when level is non-nil. Both produce raw deflate (windowBits = -15).

  should extract helpers to avoid increasing it.
