## 1. Core Objective

Implement three features for SwiftZIP v0.2.0 (Writer Deflate, modification timestamps,
ZIP64 extensions) following TDD workflow, then produce a phased roadmap for turning the
library into a full CLI tool.

## 2. Design Decisions

- **Decision:** All three v0.2.0 features implemented in a single design proposal cycle
- **Rationale:** Features are interdependent (ZIP64 affects writer layout, timestamps affect both reader/writer)
- **Alternatives Considered:** Implementing each as a separate release; rejected because the writer refactor touches the same code paths

- **Decision:** CLI roadmap uses subcommands (`swiftzip create/extract/list`) instead of Info-ZIP's flag-based mode
- **Rationale:** More discoverable, avoids legacy flag overloading; users can alias for compatibility

- **Decision:** Library target stays zero-dependency; CLI target adds ArgumentParser
- **Rationale:** Embedding the library in apps shouldn't pull in CLI framework dependencies
